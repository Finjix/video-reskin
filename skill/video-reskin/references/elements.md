# 换元素

以每条原片为单位勘察一次，选出观众在手机上正常播放就能一眼认出变化的目标。按原动作设计替代物。例如把原木换成青竹时，开场的大原木要有竹节和中空切口，劈下的短料、角色背运的物资和传送带上的竹段也要能互相对应。给每版写清「原元素 → 替代物」与交付名。多个版本都从同一原片起步。

## 怎样选醒目的目标

一起看几个候选的出现数量、首次清楚入镜时间、占屏大小、累计可见时间，以及被截断或遮住多少。优先选成片的货堆、来回通过画面的车队、占据前景的大件等。单个物体也可以入选，例如在开场占据大半画面的主角座驾。一台晚出现、经常只在画面边缘露出一角的机器，优先级低于从开场贯穿加工、搬运和销售的物资。

给入选目标记录一条与备选对象的比较理由，并挑出最早能清楚看见、变化最明显和后面再次出现的帧。替代效果也要过这一关：在手机大小的预览里快速播放，看颜色、轮廓、材质或结构是否足以区分两版。辨认仍要靠放大或长时间查找时，换更醒目的目标或更有辨识度的替代物。同一强目标可以出多个版本，例如亮色桦皮和带节、中空的绿色竹材。

## 建工单与选镜头

通过 `scripts/video_reskin.cmd init --work-order order.json --job-dir <工作区>/temp` 初始化。示例工单如下，`output_root` 是成片直接写入的目录。

```json
{"sources":["D:/footage/source.mp4"],"style":"elements","output_root":"D:/delivery"}
```

运行 `survey --job-dir <工作区>/temp --only S01` 查看带原生帧号的采样图。`survey --at 3.25` 可以看指定秒数的原尺寸帧。记录目标进出画、遮挡和再出现的区间，范围采用原片帧号，含起点、不含终点。保留尾板和非游戏镜头。

## 制作替换

- **平移跟踪素材**适合能用一张透明素材完全盖住原物、大小和视角基本稳定的镜头。使用与游戏一致的光向、轮廓和纹理，按需取一张清晰原帧制作素材。提供缩放后的像素尺寸与跟踪点 `[原片帧号, 左上角 x, 左上角 y]`。两点之间作线性插值，范围之外显示原片。
- **局部合成**适合旋转、成堆、被遮挡或会换视角的物体。从原片制作与其同尺寸、同帧数、同显示时间的候选视频。跟踪蒙版或表面网格，保留遮挡物、接触阴影和运动模糊。新轮廓盖不满旧轮廓时，用相邻帧或局部重绘补出露出的背景。合成单帧样张能解决材质和轮廓时可直接渲染，只有外观或运动难以判断时才补参考帧。音频最终取自原片。

使用 FFmpeg 传递原始 YUV 帧时，按原片标注输入和输出两端的色彩矩阵及范围，例如 BT.709、limited。用无损候选的目标外区域与原片做像素对比，可以发现全画面偏色或解码错位。

以下示例的第一版使用局部合成，第二版使用透明素材。把计划保存为 `variants.json`，执行 `plan --job-dir <工作区>/temp --input variants.json`。若初始化前已完成勘察，也可直接在工单中填写同一个 `variants` 数组。

## 核对与交付

后续命令都带 `--job-dir <工作区>/temp`。执行 `render` 和 `check`，打开每版返回的原片与成片对照页。`--only V01` 可单独处理一版，省略则处理全部。`target_selection` 是可选工单字段，包含比较理由和按填写顺序优先展示的帧号；旧工单仍可直接使用。先在首页看这组镜头是否醒目，再核对快速移动、遮挡边缘和末次退场。关注是否露出旧物、串色、漂移，以及计数、字幕、尾板是否保持原样。有疑点时用 `check --only V01 --at 3.25` 看原尺寸或播放该段。需要返修时更新对应素材，重新渲染并检查该版。

如要调整跟踪点、时间范围或抽查帧，可修改对应版本，重新提交整份 `variants.json`，再用 `--only` 渲染和审核改动的版本。

成堆物料会在移动和遮挡时分成几簇。分别跟踪仍留在地面的料、角色背上的料和落到传送带上的料，直到每一簇离开画面。挑一段完整的拾取、转身、搬运和卸料动作，把原片和成片按原帧率同步播放。注意料堆是否突然露出原色、切面是否跳亮，以及与物料重叠的计数文字和栏杆是否串色。发现闪动时逐帧查看前后画面，区分游戏本身的拾取亮光与材质跳变。共用同一套跟踪的版本，在相同时间点一起复核。

通过后执行 `approve`、`assemble`。每版按工单给定的文件名导出 MP4，沿用原片帧序和节奏，并保留原声。可用 `status` 查看各版状态。
