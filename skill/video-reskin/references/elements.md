# 换元素

以每条原片为单位勘察一次，选出观众在手机上正常播放就能一眼认出变化的目标。一版可以换一个元素，也可以把多个元素合成在同一份成片里。逐项写清「原元素 → 替代物」，每份成片单独命名，直接从原片制作。

## 怎样选醒目的目标

一起看几个候选的出现数量、首次清楚入镜时间、占屏大小、累计可见时间，以及被截断或遮住多少。优先选成片的货堆、来回通过画面的车队、占据前景的大件等。单个物体也可以入选，例如在开场占据大半画面的主角座驾。一台晚出现、经常只在画面边缘露出一角的机器，优先级低于从开场贯穿加工、搬运和销售的物资。

给入选目标记录一条与备选对象的比较理由，并挑出最早能清楚看见、变化最明显和后面再次出现的帧。把外观设计落实到可见结构，例如青竹的管壁、竹节与空心切面，或翻斗车厢的铆钉、斜侧板与翻转轴。先在手机大小的样张上辨认轮廓、截面、部件或堆叠方式，再用配色和纹理加强差异。按用户明确指定的品种、结构或配色制作。替换后仍要讲得通，角色能拿起、加工、装载并交付这种物资。

**禁止替换钞票。** 地上的纸币、交付款台上的钱捆、角色背负的钱叠、消费时飞散的钞票以及金额界面均保留原片的外形、颜色、数量变化和运动。参考图保持原片当时的现金状态，包括清空后的货台。即使钞票与目标共用背运、掉落或拾取动作，也只改选中的物资。

冰冻版可以直接沿用原模型，在表面贴合一层明显的厚冰。冻木透过冰层仍能看见树皮和年轮，冻肉仍保留原来的形状和切面。参考图和 Seedance 提示词都使用同一处理方式，让观众在手机上能看清边缘的冰层厚度。搬运、掉落和转弯时，冰层跟随物体一起运动。按同一设计给近景大件、加工后的碎件和远处料堆做样张。多版方案里同时保留非冰冻造型，如空心竹束或带铆钉的木箱，冰冻只在合适的版本使用。

同一原对象可以出多个不同替代方案。一次交付多个版本时，把全部版本的替代物放在一起比较，包含各版的每个目标。各份成片使用不同的替换结果，同一种造型换称呼也算重复。工单会检查替代物描述与可选的 `replacement_key`，比较时统一全半角等兼容字符、折叠大小写并去掉空白。给同义名使用同一个 `replacement_key`。看参考板复核实际轮廓和外观，遇到跨版本复用就更换方案。

## 建工单与选镜头

通过 `scripts/video_reskin.cmd init --work-order order.json --job-dir <工作区>/temp` 初始化。示例工单如下，`output_root` 是成片直接写入的目录。

```json
{"sources":["D:/footage/source.mp4"],"style":"elements","output_root":"D:/delivery"}
```

运行 `survey --job-dir <工作区>/temp --only S01` 查看带原生帧号的采样图。`survey --at 3.25` 可以看指定秒数的原尺寸帧。记录目标进出画、遮挡和再出现的区间，范围采用原片帧号，含起点、不含终点。保留尾板和非游戏镜头。

## 按动作做参考板

在任务临时目录做一张紧凑对照板。每行写上目标、阶段和原生帧号，左侧放原片，中间放同视角的替代结构，右侧放按手机播放大小缩小的参考样张。已有一行能说明相同尺度、视角与遮挡时可直接复用。出现截面变化、远近切换或新的遮挡关系时补一行。

| 原片阶段 | 板上需要辨认的细节 |
| --- | --- |
| 近景加工 | 大件轮廓、截面厚薄、数量，以及切开后的小件结构 |
| 地面料堆与远景 | 单件缩小后仍可见的外形、朝向、堆叠层次和留在地面的余料 |
| 拾取、背运与转身 | 转到侧面后的外形，角色身体、手、计数文字与物资的前后关系 |
| 交接与卸料 | 穿过栏杆或车厢边缘时的遮挡、装载位置、末次退场及再出现 |

同版多个目标共用涉及交叠的原帧，例如货车和货物都替换时，在装车阶段的样张上同时核对车沿、货物和角色。用 `target_selection.frames` 记录板上的代表帧，可在 `target_selection` 中附上参考板路径作为工单备注。

按实际动作标注参考图和审核时间。过桥超载和随后正常过桥、空车和装煤、地面发钱和角色取走都可能使用同一机位。分别查看动作前后两帧，在参考图里保留各自的空货台、桥栏、背包和已装的货物。只出现车斗的画面只提供车斗样图，原片车斗和绿钞同框时，场景参考图保留原绿钞。原木和黑煤共用背运姿势时，标明原木的具体位置，以及黑煤、钞票在该时刻的颜色、形状和运动。

## 由 Seedance 编辑视频

新建替代物参考图统一通过 Lumos 图生图。阶段中省略 `references`，填写原片帧号 `reference_frame` 和静帧说明 `reference_prompt`。默认取该阶段首帧并沿用阶段提示词。比如冻木可写“沿用原木模型，包一层可见树皮的厚冰”。先用 `plan` 本地查看 `image_tasks` 的数量。执行 `refs --job-dir <工作区>/temp --only V01` 才会提交这些生图任务。它们独立于视频提交额度。核对返回图片后再运行 `render`。同一原帧和设计重复使用时会复用已生成的图片，已有成图可直接写入 `references`。

每个替换区段向 Seedance 提交对应的原片视频、至少一张替代物参考图以及编辑说明。参考板用于选图，将该阶段清晰、匹配视角的图放入 `references`。在 `prompt` 写明原对象、替代物的结构、在整段动作中的变化，以及需要保留的镜头、角色、文字和遮挡关系。Seedance 返回的视频构成成片中的替换画面。后期负责裁切、对齐、拼接原片、恢复原声与尾板，并制作审核材料。历史工单已有的本地素材与成片可供回看。

**切片与换风格共用同一个规划器。** 工单可用 `surveys.S01` 传入换风格勘察得到的 `non_game`、`end_card_start`、`cuts`（秒）。同一原片的各版共用这份勘察。连续玩法沿用换风格的最少段数和语义切点规则，30 秒是服务上限。锤击、运输、收钱等写进 `seedance.stages`，原生帧范围用来安排参考和提示。规划器把同一生成片段覆盖的动作合并为一次请求。整段没有目标时跳过，片段内目标全离场的画面从原片恢复。

**先盘点已有回包和预算。** `plan` 在本地列出实际生成片段数。换元素工单的 `generation_limit` 是这批全部版本共用的提交总上限，默认 0，只可复用。按用户确认的额度填写，必要时只送一个代表段验证设计。首发计一次，每个源片段最多再试两次，失败与提交后未收到明确回执也占用额度。改变参考图、细分区间或移动切点都不能重置已覆盖帧的次数。把所有版本和返工留在同一工单。对已有结果的查询、下载、原速对照和本地选段不占生成额度。

视频编辑输入为 4 至 30 秒。短动作保留实际可见区间，上传副本以末帧补足 4 秒，输出时按原片帧号截回。选清晰度足够的参考图，图像短边低于 300 像素时工作流会等比放大上传副本。

同版多目标用 `targets` 逐个登记，每个目标可单独写 `ranges`，省略时继承版级 `ranges`。单目标可直接写版级 `element`、`replacement` 和 `ranges`。两个目标同时入画时，提示词分别说明它们的结构、相互遮挡及出现时间，由模型在同一画面内处理。一份计划输出一条命名成片。

## 核对与交付

后续命令都带 `--job-dir <工作区>/temp`。`render` 后执行 `check`，用 `--only V01` 可单独处理一版。先打开返回的对照页，在优先展示的代表帧上核对结构和遮挡。用 `check --only V01 --at 3.25` 可以检查指定时间的原尺寸帧。

动态审核按实际动作覆盖所有替换时段，从入画、形变、遮挡一直看到末次退场。可用 `motion_review` 为原生帧区段命名，包含进出画前后的原片。`check` 按时间顺序输出可播放的静音 MP4，左边原片、右边成片，保留全部连续帧与原播放间隔。Seedance 处理过的区段中，已命名的动作沿用原名，其余部分按帧号补齐。整份计划省略 `motion_review` 时，会自动按模型区段出片。正常速度逐段从头看到尾，关注重复出现的动作以及多个目标同时在场的时刻。文件路径、原帧范围和校验和记录在本版 `check.json` 的 `motion_clips` 中。历史本地工单可用 `check` 查阅已有成片。

在本版 `render.json` 的 `generations` 中核对各段的原片帧范围、模型、生成 ID 和返回视频校验和。结合对应的输入参考图和原速成片确认生成内容。发现形状、动作或遮挡错误时，调整提示词或参考图，把原视频区段重新交给 Seedance 编辑。更新 `variants.json` 后用 `plan --input` 登记，再用 `--only` 渲染并审核受影响的版本。只调整审核帧、勘察备注或 `motion_review` 时，重新 `check` 可复用已有模型画面。

先对照同一时刻的货物种类、数量和货台空满，再查看替代物是否稳定。若某个动作出现误改，先查同版本已生成的其他回包，保留合格时间窗，用实际生成画面离线择段。需要再试时，在原生成片段内更新该动作的样图或说明，沿用同一片段的重试额度。在 `status` 中可查看逐段的生成 ID 和本地收件状态。

成堆物料会在移动和遮挡时分成几簇。分别跟踪地面余料、角色背上的料和落到带面上的料，直到每一簇离开画面。核对原色回闪、切面跳亮、轮廓漂移及遮挡物串色，特别看靠近物料的数字字面、栏杆立柱、手和货箱边缘。发现闪动时逐帧检查前后画面，对照游戏本身的拾取亮光。共用跟踪的版本在相同时间段一起复核，返修后重看整段连续动作。

通过后执行 `approve`、`assemble`。每版按工单给定的文件名导出 MP4，沿用原片帧序和节奏，并保留原声。可用 `status` 查看各版状态。
